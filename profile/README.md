## What we are building

omitt is a native macOS utility for copied text, PDFs, images, and screenshots. It finds supported sensitive text, IDs, card numbers, secrets, IP addresses, faces, and barcodes, then lets the user review every mark before creating a clean copy.

## Privacy boundary

- Document processing happens on the Mac
- Documents, screenshots, images, and clipboard content are not uploaded
- No analytics or usage telemetry
- Optional feedback sends only what the user explicitly enters after pressing Send

The landing page is live at [omitt.app](https://omitt.app). The app is currently in pre-beta release acceptance and is not yet available as a signed public download.
